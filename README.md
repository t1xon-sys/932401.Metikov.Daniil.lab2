# Лабораторная работа №2. Базовые и продвинутые возможности CSS
**Тема (Вариант 1):** «Студент-разработчик» — эффект «карточки навыков» с анимацией масштаба.
## Цель работы
Научиться подключать стили, работать с селекторами, типографикой, цветами, отступами, позиционированием и псевдоклассами.

### 1. Три способа подключения CSS
**Внешний файл** — `style.css`, содержит основную часть стилей (макет,
  типографика, карточки навыков, форма).
- **Inline-стиль** — у `<header>`:
```html
  <header style="padding: 20px;">
```
- **Внутренний блок `<style>`** (в `<head>` `index.html`):
  - правило для первой карточки навыка (`.skill-card:nth-child(1)` — пунктирная рамка);
  - стили поля «Email» (`#email`): увеличенный `padding`, `border-radius` и
    смена цвета рамки при фокусе (`#email:focus`).

### 2. CSS-переменные (`:root` в `style.css`)
`--color-main`  (`#1e5aa8`) - основной синий цвет
`--color-accent` (`#0d2f5e`) -  тёмно-синий акцент
`--color-bg` (`#f0f6ff`) - фон страницы
`--color-card-bg` (`#ffffff`) - фон карточек и `main`
`--color-text` (`#222222`) -  основной цвет текста
`--shadow-soft` / `--shadow-strong` - тени для `:hover` / `:active`
`--font-main` / `--font-heading` - шрифты основного текста и заголовков

### 3. Позиционирование
**`static`** — используется по умолчанию для `body` (обычный поток документа).
 **`relative`** — контейнер сетки навыков `.skills-grid` и обёртка карточки
  `.top-skill` задают точку отсчёта для дочерних абсолютных элементов.
 **`absolute`** — декоративный бейдж `.badge` («Top skill») позиционируется
  в правом верхнем углу карточки Python: `top: -10px; right: -10px;`.

 ### 4. Карточки навыков — сетка и анимация
 Навыки оформлены как сетка плиток: `.skills-grid { display: grid; }`.
 **`:hover`** — карточка плавно увеличивается (`transform: scale(1.05)`) и получает мягкую тень (`box-shadow: var(--shadow-soft)`).
 **`:active`** — карточка слегка уменьшается (`transform: scale(0.98)`) и тень становится плотнее (`box-shadow: var(--shadow-strong)`).
 Переход между состояниями плавный за счёт `transition: transform 0.25s ease, box-shadow 0.25s ease;`.

 ### 5. Псевдоклассы
 `:hover` — карточки навыков, кнопка «Отправить».
 `:active` — карточки навыков.
 `:focus` — поле «Email»: рамка меняет цвет с `--color-main` на `--color-accent`.

 ### 6. Контрастность текста
 Все пары «текст / фон» подобраны с контрастом не ниже 4.5:1, например:
 - `#222222` на `#f0f6ff` (основной текст);
 - `#0d2f5e` на `#ffffff` (подписи `label`, текст карточек);
 - белый текст на `#1e5aa8` (шапка, подвал, кнопка).
